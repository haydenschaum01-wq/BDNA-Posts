# BDNA-Posts

Finished images for BoxDrop North Austin's Facebook and Instagram posts. This repo is public so Facebook can pull each photo from its raw GitHub address when a post is scheduled.

- Layout: `YYYY/MM/<post date>-<slug>.jpg`, dated by the day the post goes out.
- A post's main image is the 4:5 one (`<slug>.jpg`). Square (`-square`) and 9:16 story (`-story`) versions sit next to it.
- Only finished images go here. Drafts, render scripts, the voice guide and page stats stay in the private poster repo under `content/`.
- Don't rename or delete an image a scheduled post uses: its address would break.
